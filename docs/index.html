What an experiment contains

  • A physical setting: star, orbit, planet, surface grid, climate and biomes.
  • Genomes, metabolic budgets, brain architecture and individual behaviours.
  • Demography, predation, disease, technology and cultural transmission.
  • Interventions at chosen ticks, followed by comparable outcomes.

Each report shows the population trajectory, technology and cognition curves, the final surface map with settlements, species outcomes, causes of death and behaviour mix.

Run it yourself

Clone the template and reproduce any report. Node 22.18+ runs the TypeScript directly.

npm install
npm run sim -- run scenarios/earthlike.ts
npm run sim -- compare scenarios/earthlike.ts \
  scenarios/hypercognitive.ts --ticks 300

The seed and state digest are printed in every report, so two runs can be compared mechanically.
